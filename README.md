# Library Management System 📚

A simple, user-friendly Library Management System built in Java. Designed to help manage books in a library with functionality to add, remove, search, sort, and import/export book data. Perfect for small libraries, schools, and personal projects.

## Features 🌟

- **Add books**: Title and Author fields
- **Remove books**: Click to remove a selected book
- **Search**: Easily search books by title or author
- **Sort books**: Sort by title or author
- **Clear all books**: Remove all books from the library
- **Import/Export books**: Import books from a CSV file and export to CSV
- **Persistence**: Books saved in a file for easy access

## Installation 💻

### Prerequisites:
- Java (JDK 8 or later)
- Git

### Setup Instructions:

1. Clone this repository:
    ```bash
   git clone https://github.com/Intellectual-Tarange/BYTEUPRISE_JP_02.git
    ```

2. Navigate to the project folder:
    ```bash
   cd C:\Users\HP\Desktop\LibraryManagementSystem\BYTEUPRISE_JP_02\src

    ```

3. Compile the project:
    ```bash
    javac -d ..\bin com\library\*.java com\library\logic\*.java com\library\ui\*.java

    ```

4. Run the application:
    ```bash
    java -cp ..\bin com.library.LibraryManagementSystem

    ```

## Usage 🎮

1. **Add books**: Enter the title and author, then click "Add Book".
2. **Remove books**: Select a book from the table and click "Remove Book".
3. **Search**: Type part of the title or author in the search box and press "Search".
4. **Sort books**: Click "Sort by Title" or "Sort by Author" to sort your list.
5. **Clear all books**: Click "Clear All" to remove every book from the system.
6. **Import books**: Upload a CSV file with book data (e.g., `sample_books.csv`).
7. **Export books**: Save all books to a CSV file.
